# **App Name**: QueuePilot

## Core Features:

- Real-Time Queue Display: Display the current queue status and estimated wait times in real time.
- Token Generation: Allow users to generate new queue tokens.
- Role-Based Dashboards: Provide role-based dashboards for staff and admins to manage the queue.
- Automated Notifications: Send automated notifications to users when their token is about to be called using a tool.

## Style Guidelines:

- Primary color: A calming blue (#5DADE2) to evoke trust and efficiency.
- Background color: Light gray (#F0F4F7), a desaturated shade of the primary.
- Accent color: Soft green (#A8E6CE) for a modern and fresh look. 
- Body and headline font: 'Inter', a sans-serif with a modern, machined, objective, neutral look.
- Use simple, clean icons to represent queue status, token types, and dashboard functions.
- Design a clear, intuitive layout for easy navigation and quick access to information.
- Use subtle animations to indicate real-time updates and changes in queue status.
